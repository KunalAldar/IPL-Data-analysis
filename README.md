# 🏏 IPL Data Analysis (Exploratory Data Analysis) using Python

This project involves exploratory data analysis (EDA) on the Indian Premier League (IPL) dataset using Python. The goal is to uncover insights and trends related to teams, players, matches, and overall performance over the seasons.

## 📁 Dataset

The dataset used for this analysis contains information on IPL matches and deliveries. It includes:

- Match-level data (teams, venue, toss results, winners, etc.)
- Ball-by-ball delivery data (batsmen, bowlers, runs, dismissals, etc.)

> Source: [Kaggle IPL Dataset]([https://www.kaggle.com/datasets](https://www.kaggle.com/datasets/ramjidoolla/ipl-data-set))
> Maybe updated according to present date

## 🛠 Tools & Libraries Used

- **Python**
- **Pandas** – for data manipulation
- **Matplotlib** – for basic plotting
- **Seaborn** – for advanced data visualization
- **Jupyter Notebook**

## 📌 Key Analysis Performed

- Total matches played and teams involved
- Most successful teams (based on match wins)
- Toss impact: teams that win the toss vs win the match
- Top venues by number of matches hosted
- Most frequent player of the match award winners
- Runs distribution: match with highest and lowest runs
- Dismissal types and bowler performance
- Top run-scorers and most wickets
- Batsman Vs Bowler stats

## 📊 Visual Insights

The notebook includes a variety of insightful visualizations such as:

- Bar plots of top-performing players
- Pie chart of toss decision preferences
- Count plots for match wins by teams and venues
- Pivot tables for death over anlysis

## 🔍 Sample Insights

- Teams winning the toss choose to field more often.
- M. S. Dhoni appears among top players in match appearances and wins.
- Eden Gardens and Wankhede Stadium host the highest number of matches.
- The number of matches and participating teams has increased over the years.
